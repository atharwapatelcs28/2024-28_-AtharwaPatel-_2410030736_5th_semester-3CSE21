## 📌 About the Internship

The internship focused on practical concepts of Artificial Intelligence, Python programming, data preprocessing, machine learning, Natural Language Processing (NLP), and model evaluation applied to text classification. The end-to-end workflow involved building a spam email detection system by preparing datasets, performing feature extraction, training baseline classifiers, and evaluating prediction performance.

**Organization:** Codec Technologies Pvt. Ltd. (Google for Education Partner)[cite: 1, 2] — conducted under the patronage of the AICTE National Internship Portal[cite: 1, 2].

---

## 🎯 Objectives

* Understand spam filtering as a supervised text-classification problem.
* Clean and preprocess textual data using normalization, tokenization, and noise handling.
* Convert email text into numerical feature vectors using TF-IDF.
* Train and evaluate machine-learning models (Logistic Regression, Naïve Bayes, SVM, Random Forest).
* Analyze classification performance using Precision, Recall, F1-Score, and Confusion Matrix metrics.
* Establish an end-to-end pipeline for predicting spam/ham labels on unseen email messages.
